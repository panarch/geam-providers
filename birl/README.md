# geam-birl

This crate implements the three Erlang native externals of the unchanged [`birl` 2.0.0](https://hex.pm/packages/birl/2.0.0) Gleam package through Geam's public typed provider API. Add `birl` to the Gleam project and select `geam-birl` and the existing `geam-regexp` provider. `gleam_time` is supplied by Geam's built-in Time component. The verified `birl` package range is 2.0.0 only. The [standalone fixture](fixtures/gleam/) and [Rust embedding fixture](fixtures/embedding/) use the original Hex packages; no local Geam path is a dependency.

`monotonic_now` reports microseconds since a stable origin captured when the provider run begins. `weekday` computes the local calendar day from a Unix timestamp and offset in microseconds and returns Monday as 0 through Sunday as 6. `local_timezone` supplies an optional IANA name. The original Gleam code still builds `Time`, validates the name against `birl/zones`, and performs `compare` and `difference`. The absolute monotonic number is not the BEAM VM's start time; elapsed values, order, and units are the supported contract.

The default `SystemSource` uses the host monotonic clock and Jiff's system time-zone discovery, matching the source Geam's built-in `gleam_time` uses for local UTC offset. An embedding host can implement the public `Source` trait and install `RunState::with_source` through Geam's `HostComponentProfile<geam_birl::Component>` projection. The generated embedding profile separately accepts a `gleam_time::TimeSource`, so callers can supply both from one controlled host configuration. The provider configuration has no keys; an empty configuration chooses `SystemSource`, and an unknown key is rejected during initialization.

System time-zone discovery can differ from `birl`'s Erlang FFI. Jiff checks `TZ` and `/etc/localtime` on Unix and maps the Windows system zone through CLDR. The Erlang implementation also checks `/etc/timezone` and uses its own Windows mapping. This provider returns `None` when no IANA name is available; the unchanged Gleam body also turns names absent from `birl/zones` into `None`. Jiff's `UTC` name is presented as `Etc/UTC`, which `birl/zones` contains. Hosts that need a particular name and UTC offset should supply them explicitly in embedding.

The fixtures pin `gleam_stdlib` 1.0.3, `gleam_time` 1.8.0, `gleam_regexp` 1.1.1, `ranger` 1.4.0, and `gleam_yielder` 1.1.0 with Geam `main` commit `bd95b872c578df88f76ed5c4175fb1ea55ee8607`. The companion `geam-regexp` provider must include captured groups in `regexp.split`; `birl` uses that behavior to parse signed offsets. See the [testing guide](../docs/development/testing.md) for fixture, coverage, and packaging checks. Registry publication and consumption remain separate while Geam is Git-pinned.
