# Geam Providers

이 저장소는 기존 Gleam 패키지의 native 함수를 Geam의 공개 provider API로 구현합니다. 각 패키지의 Rust provider는 독립적인 Cargo workspace member로 추가합니다.

코드 검토 기준은 [리뷰 정책](docs/development/review-policy.md), 테스트 구성과 커버리지 기준은 [테스트 지침](docs/development/testing.md), 테스트 작성 방법은 [테스트 개발 지침](docs/development/test-development.md)에 있습니다.

라이선스는 [Apache-2.0](LICENSE)입니다.
